# Cable Simulation - LTspice

This repository contains an LTspice simulation project focused on the electrical behavior of cables and conductors made for the Comunication Systems course.

## Objective

* Analyze the electrical behavior of a cable/conductor model
* Simulate the circuit using LTspice
* Observe voltage, current and signal behavior in the simulated system
## Tools

* LTspice

## Repository structure

* `simulation/`: LTspice schematic files
* `docs/`: project report or technical documentation
* `images/`: simulation screenshots, plots or circuit images
* `results/`: relevant outputs and simulation results

## Files

* `cable_simulation.asc`: LTspice schematic file


This project was developed for academic and portfolio purposes.
